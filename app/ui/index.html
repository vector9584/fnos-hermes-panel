通用模型

平时所有对话走主模型；主模型报错、超时或额度用完，才按回退顺序往下换。再往下是服务商：一家服务一条卡片，地址、密钥、这家能提供哪些模型，接口协议（Chat Completions / Responses / Anthropic Messages）也在卡片里选。停用只是暂时不参与选择，不删配置。

模型 API

方向反过来：不是我们去调别人，是把本机 agent 当模型给别的程序调。地址、端点、鉴权状态都在这。

辅助模型

图像理解、上下文压缩、会话标题这十一样旁活可以单独指定模型；不指定就跟着主模型走。

组合模型

几个模型各答一遍，再让聚合模型挑或合成。比回退贵得多，默认不开。

JEV

有界的判断副驾：外部判定后端回答「这句合不合规、该不该拦」。不是对话模型，也不顶替主模型。

STT 提供方

语音条转文字用谁：本地 Whisper 不上传音频，云端更快。改完重启应用生效。

TTS 提供方

你听到的那副嗓子。换提供方只影响之后的合成，已经发出去的语音不会变。
